# Git workflow

<!-- No `paths:` frontmatter — this applies always, not just when editing certain files. -->

- Branch naming: `<type>/<short-description>` (see global naming defaults).
- Commit style: Conventional Commits (see global defaults) unless this project already uses
  something else — if so, replace this line with what it actually uses.
- Never force-push to `main`/`master` without asking first (also covered by the global
  confirmation defaults, restated here since git history loss is high-cost).
- PR process: <e.g. "open a draft PR, request review from X before merging">
